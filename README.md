# Pakistan Tourism — By the People of Pakistan

A short, interactive frontend website showcasing tourism in Pakistan, told from the people of Pakistan.

**Live site:**  https://dawoodurrehman-david.github.io/pakistan-tourism/

## Destinations

- **Hunza Valley** — autumn valleys, Rakaposhi, Karimabad
- **Skardu / Shangrila Lake** — lakes, mountains, cold desert
- **Swat Valley** — rivers, green valleys, Mingora
- **Islamabad** — Faisal Mosque, Margalla Hills
- **Lahore** — Badshahi Mosque, Lahore Fort, food streets
- **Mohenjo-daro** — ancient Indus Valley civilisation
- **Karachi** — Clifton Beach, city by the sea

## Features

- Clean, responsive design — works on phone and desktop
- Destination cards with real photos
- Category filters (Mountains, Heritage, City, Beach) and live search
- Save destinations to favourites
- Destination detail pop-ups
- Season-by-season travel guide
- Regional food section
- Trip planner: build a day-by-day itinerary (3–14 days, 4 routes) and copy it

## How to use

1. Download or clone this repository.
2. Open `index.html` in any modern browser. No build step, no server needed.

```bash
git clone https://github.com/DawoodUrRehman-David/pakistan-tourism.git
cd pakistan-tourism
# open index.html
```

## Tech

- Single-file HTML, CSS and JavaScript
- No framework, no backend
- Photos embedded in the page, so it works offline after first load
